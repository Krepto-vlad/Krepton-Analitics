### 1. Механическая ребалансировка «Новыми деньгами» (Deposit-based Rebalancing)

Большинство инвесторов **не хотят продавать акции** для ребалансировки, потому что это создает налоговое событие (налог на прирост капитала) и комиссии.

- **В чем идея:** Пользователь заводит свои целевые доли (например, 60% VOO, 20% VXUS, 20% Bonds). Но вместо банального советника «продай А, купи Б», у тебя есть режим **«Пополнить портфель»**.
- **Как это работает:** Инвестор вводит: *«У меня есть $1,000 свежих денег на этот месяц»*.
- **Математика (без всякого ИИ!):** Приложение рассчитывает текущие отклонения и говорит: *«Чтобы максимально приблизиться к своей идеальной стратегии без продажи активов и без уплаты налогов, распредели эту $1,000 так: $600 в Bonds, $400 в VXUS. VOO в этом месяце не покупай»*.
- **Почему это киллер-фича:** Это чистая, честная математика. Это экономит человеку налоги и 30 минут сидения с калькулятором каждый месяц.

~~Модуль 2. Калькулятор ребалансировки портфеля~~
Брокеры показывают, сколько у тебя акций, но они не умеют подсказывать, что купить, чтобы соблюдать стратегию.

Функционал для пользователя: Ты задаешь желаемые пропорции своего идеального портфеля. Например: «Я хочу, чтобы у меня было 40% IT-сектора, 30% Нефтегаза, 20% Золота и 10% Кэша». Система анализирует твой текущий портфель, видит перекос (например, IT выросло до 50%, а Нефтегаз упал до 20%) и выдает четкую инструкцию: «Чтобы вернуться к стратегии, вам нужно докупить 5 акций Лукойла и 2 акции Роснефти. Для этого потребуется ХХХ рублей».

Как это работает под капотом: Чистая математика на Node.js. Бэк запрашивает текущие цены акций, считает текущие доли, сравнивает с целевыми и выдает массив рекомендаций. На фронте это оформляется в виде красивых сравнительных диаграмм «Было / Должно стать».

Ценность для диплома: Готовая бизнес-логика. Показываешь, что умеешь писать алгоритмы, а не просто перекладывать данные из базы на экран.

~~Модуль 3. Календарь пассивного дохода (Дивиденды и купоны)~~
Брокеры показывают дивиденды только тогда, когда их уже утвердили. Прогнозировать доход на год вперед они не умеют.

Функционал для пользователя: Вкладка с интерактивной гистограммой по месяцам. Ты видишь свой ожидаемый пассивный доход на ближайшие 12 месяцев на основе тех акций, которые уже лежат в твоем портфеле. Система подтягивает даты прошлых закрытий реестров и прогнозирует будущие выплаты.

Как это работает под капотом: Node.js через Yahoo Finance API запрашивает историю дивидендов по тикерам из твоего портфеля, считает среднюю выплату в год/квартал и строит календарь выплат.

Ценность для диплома: Отличная работа с визуализацией сложных временных данных на фронтенде.

~~Модуль 4. Сравнительная матрица акций (Мини-скринер)~~
Инструмент для принятия решений перед покупкой.

Функционал для пользователя: Ты сомневаешься, что купить: Сбербанк или ВТБ (или Apple против Microsoft). Ты вводишь оба тикера, и приложение строит таблицу сравнения по ключевым мультипликаторам (P/E, P/S, ROE, долг/капитал, див. доходность). При этом система сама подсвечивает зеленым цветом те показатели, которые у компании объективно лучше.

Как это работает под капотом: Фронтенд запрашивает сравнение двух тикеров. Бэкенд за один запрос собирает фундаментальные данные из Yahoo Finance quoteSummary API и отдает на фронт, где простая логика компонента React подкрашивает ячейки таблицы.

Ценность для диплома: Наглядная визуализация + умение работать с богатыми финансовыми данными API.

~~Модуль 5. Дашборд «Здоровье портфеля» (Risk Score)~~
Каждый инвестор хочет знать — насколько рискованно то, что у него собрано?

Функционал для пользователя: На главной странице портфеля — одна большая цифра «Риск-скор» (например, 67/100) и расшифровка: «Ваш портфель сильно сконцентрирован в IT (72%). Рекомендуем диверсифицировать». Рядом — пай-чарт по секторам (Technology / Energy / Finance / Gold / Cash).

Как это работает: Считается на бэкенде по набору простых правил: концентрация в одном секторе > 50% = высокий риск, > 3 активов = низкий риск концентрации, доля волатильных активов и т.д. Yahoo Finance возвращает sector/industry для каждого тикера через quoteSummary.assetProfile.

Ценность для диплома: Собственный алгоритм оценки риска. Круто смотрится на защите.

~~Модуль 6. Трекер сделок с аналитикой P&L~~
Брокеры показывают прибыль/убыток, но не объясняют — на чём именно ты заработал или потерял.

Функционал для пользователя: Таблица всех твоих сделок с колонками: тикер, дата покупки, цена входа, текущая цена, количество, P&L в деньгах, P&L в процентах. Плюс график «Кривая доходности портфеля» — как рос твой капитал по дням с момента первой сделки.

Как это работает: Сделки берутся из БД (импортированы через модуль 1). Исторические цены на дату покупки запрашиваются через /history endpoint, который уже реализован. P&L = (текущая цена - цена покупки) * количество.

Ценность для диплома: Полноценная работа с PostgreSQL (JOIN'ы, агрегации) + красивые временные графики.

~~Модуль 7. Watchlist (Список наблюдения) с алертами~~
Классика любого торгового терминала. Есть у Interactive Brokers, нет в нормальном виде у российских брокеров.

Как это работает: Watchlist хранится в PostgreSQL. WS-поллер на бэкенде проверяет условия алертов при каждом обновлении цены и шлет push-уведомление через браузерный Notifications API.
