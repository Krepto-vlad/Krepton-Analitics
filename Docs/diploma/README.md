# Diploma thesis

The thesis source is [thesis/](./thesis/). Build it with MkDocs (`thesis/mkdocs.yml`).

Edit chapters under `thesis/docs/`. Screenshots for the thesis site stay in `thesis/docs/assets/screenshots/`. The database review pack is [../database/](../database/), not a second copy inside the thesis. The HTTP contract is `backend/openapi.yaml`.

How to run the application: the repository [README](../../README.md).
