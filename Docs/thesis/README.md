# Thesis

MkDocs source for the thesis site (`mkdocs.yml`, chapters in `docs/`). Build from this folder with `mkdocs build`.

The chapters keep the thesis structure: overview, technical, user guide, retrospective, appendices. Per-criterion material lives in its own folder under [Docs](../README.md): [BA](../BA/README.md), [backend](../backend/README.md), [frontend](../frontend/README.md), [database](../database/README.md), [AI assistant](../ai-assistant/README.md), [cloud](../cloud/README.md), [CI/CD](../ci-cd/README.md), [automated tests](../automated-tests/README.md). The HTTP contract is `backend/openapi.yaml`.

How to run the application: the repository [README](../../README.md).
